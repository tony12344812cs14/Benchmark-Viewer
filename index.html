LLM Benchmark 逐題資料集

本站收錄兩個模型路由（routing）基準：RouterBench 的 MMLU（11 個 2023 年模型）與 LLMRouterBench 效能-成本設定的 10 個資料集（13 個旗艦模型）。每一題都列出正確答案、各模型的回答與得分；LLMRouterBench 另附每題 API 成本，可用來比較效能與花費的取捨。

使用方式：點選表 1 任一列開啟資料集，以 ← → 逐題瀏覽；按右上角「使用說明」或 ? 鍵查看名詞與快捷鍵。

    資料來源
    
    
    RouterBench MMLU：withmartian/routerbench（routerbench_0shot.pkl），正解取原版 MMLU（cais/mmlu），依選項文字對應到 RouterBench 打亂後的字母。LLMRouterBench：NPULH/LLMRouterBench（bench-release.tar.gz），依官方 baseline_config_performance_cost.yaml 取 10 個資料集 × 13 個模型，成本為官方紀錄的每題 API 費用（美元）。題目與作答過長時會截斷。
    
  
    
    


  
    使用說明
    
  
    
    
    這個網站在做什麼？
    
    
    把 LLM benchmark 的每一題、正確答案、每個模型的回答、對錯和花費放在同一頁，讓你逐題比較模型，並找出「便宜模型就答得對、不必用貴模型」的題目。
    
    
    怎麼看一題
    
    
      
      
    • 左邊：題目與選項，左側紅線標示的是正確答案。用工具列的「English／中文」切換顯示語言。
      • 
      
    • 右上：正確答案、幾個模型答對，以及最便宜的答對模型。
      • 
      
    • 右下：每個模型的答案、對錯與成本，依這題的成本由高到低排列；點「完整回答」看模型的完整推理。
      • 
    
    
    
    名詞解釋
    
    
    
      
    模型名稱
    點表格中的模型名稱，右側會打開模型簡介：開發者、發布時間、參數量，以及 model card、技術報告等官方連結。
    
      
    進場動畫
    從首頁進入資料集時會播放約 3 秒的 routing 動畫，點一下或按任意鍵可略過；系統設定「減少動態效果」時不播放。
    
      
    難度
    依答對的模型比例分級：難 ≤ 1/3、中 1/3–2/3、易 ≥ 2/3。
    
      
    本題成本
    官方紀錄的這一題 API 費用（美元）。
    
      
    成本倍數
    本題成本 ÷ 這題最便宜模型的成本，最便宜為 1×。
    
      
    模型對照
    在「篩選」裡選一個模型，只看它答錯但別的模型答對的題目。
    
      
    整體答對率
    模型在目前篩選範圍內的平均得分，會隨篩選改變。
    
      
    正解來源
    MMLU 用原版 MMLU 的官方答案；LLMRouterBench 用官方的 ground truth。
    
      
    English／中文
    切換題目與完整回答的語言；中文為機器翻譯，僅供參考，數學式與程式碼不翻譯。
